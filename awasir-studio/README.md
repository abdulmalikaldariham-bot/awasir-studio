# استوديو أواصر

مولّد التصاميم الرسمي لأسرة آل دريهم. يختار المستخدم المناسبة والقالب، ويكتب البيانات، ثم يحمّل تصميماً جاهزاً بهوية أواصر خلال دقيقتين، بلا حاجة لمصمم.

**التقنيات:** Next.js 15 · React 19 · TypeScript · Tailwind CSS · html-to-image · jsPDF

---

## النشر خطوة بخطوة (حوالي ١٠ دقائق)

### ١) الرفع إلى GitHub
1. أنشئ مستودعاً جديداً على github.com (يُفضّل **خاص**).
2. فك ضغط الملف، ثم في صفحة المستودع اختر **Add file ← Upload files**.
3. اسحب **محتويات** المجلد كلها (وليس المجلد نفسه)، ثم **Commit changes**.

### ٢) النشر على Vercel
1. في vercel.com اختر **Add New ← Project** ثم المستودع.
2. قبل الضغط على Deploy افتح **Environment Variables** وأضف:

| المتغير | الغرض |
|---|---|
| `ADMIN_PASSWORD` | كلمة مرور لوحة الإدارة `/admin`. **مطلوبة**؛ بدونها تبقى اللوحة مغلقة. |
| `SITE_PASSWORD` | اختياري: كلمة مرور للموقع كله إذا أردت قصره على أفراد الأسرة. |

3. اضغط **Deploy**. عند الدخول يطلب المتصفح اسم مستخدم وكلمة مرور؛ اكتب أي اسم، والمهم كلمة المرور.

> تغيير كلمات المرور لاحقاً: Settings ← Environment Variables، ثم Deployments ← Redeploy.

## كيف تعمل لوحة الإدارة والنشر

لا توجد قاعدة بيانات في هذا الإصدار. كل القوالب والتصنيفات والنصوص الجاهزة والهوية في ملف واحد: `data/library.json`.

1. تعديلات لوحة الإدارة تُحفظ أولاً في متصفح المدير فقط، ويظهر شريط يذكّر بأنها لم تُنشر.
2. للنشر: **لوحة الإدارة ← النشر ← تحميل ملف المكتبة**.
3. في GitHub افتح مجلد `data` ← **Add file ← Upload files** وارفع `library.json` ليستبدل القديم.
4. ينشر Vercel التحديث للجميع خلال دقيقة أو دقيقتين.

**المسودات** تُحفظ في متصفح كل مستخدم على جهازه (IndexedDB). مسح بيانات المتصفح يحذفها.

## إضافة قالب جديد بدون برمجة

من **لوحة الإدارة ← القوالب ← قالب جديد**، أو انسخ قالباً قريباً وعدّله:

- **الحقول:** ما يكتبه المستخدم (نص، نص طويل، تاريخ، اختيار، رابط، رقم).
- **نصوص التصميم:** تربط الحقول بمواضعها في التصميم:
  - `{{groomName}}` قيمة الحقل.
  - `[[، {{city}}]]` مقطع يُخفى كاملاً إذا كان الحقل فارغاً.
  - `{{date|full}}` ← الخميس ١٠ محرم ١٤٤٨ هـ · وأيضاً `|hijri` و`|gregorian` و`|weekday`.
  - `{{gender|g:ابنه:ابنته}}` يختار الكلمة حسب حقل الجنس.
  - `{{signature}}` التوقيع الافتراضي (أسرة آل دريهم).
- **الأشكال:** من ٣ إلى ٦ من الأنماط الستة: رسمي، بسيط، فاخر، حديث، بالصورة، عائلي.
- **طابع المناسبة والعنصر الرئيسي:** يُختاران تلقائياً حسب التصنيف، ويمكن تغييرهما من محرر القالب.
- القالب الجديد يُنشأ **موقوفاً**؛ فعّله بعد مراجعته.

## الطابع البصري للمناسبات

القاعدة: **أواصر واضحة في كل تصميم، وروح المناسبة واضحة في كل قالب.**
الأنماط الستة (رسمي، بسيط، فاخر، حديث، بالصورة، عائلي) هي نظام التخطيط، وفوقها طبقة المناسبة من `lib/occasions.ts`:

| المناسبة | العناصر | الإبراز |
|---|---|---|
| الزواج | قوس معماري مدبب، البشت، الدلة والفنجال، الختم، الخاتمان، لمسات ذهبية | فخامة هادئة، معينات ذهبية حول العنوان |
| رمضان | فوانيس معلقة بتوهج خافت، هلال، محراب، رحل ومصحف، نجوم | سكينة، خلفية كحلية أعمق |
| عيد الفطر | زينة أعلام، هدايا، إشراقة، قصاصات هندسية | بهجة، عنوان ذهبي أكبر |
| عيد الأضحى | أفق مسجد بقباب ومآذن، النجمة الثمانية، بريق | بهجة دافئة بدرجات رملية |
| التعزية | بلا زخارف ولا عناصر احتفالية، إطار رفيع ومساحات هادئة | عنوان أهدأ ووزن أخف |
| المواليد | قمر وغيوم ونجوم معلقة | نعومة وألوان أفتح |
| التخرج والنجاح | قبعة التخرج، وسام، شارة تكريم، إطار مزدوج | خط ذهبي تحت العنوان |
| الترقيات والوظائف | حقيبة عمل، درجات صاعدة، شبكة سداسية | وسم مؤطر مهني |
| الاجتماعات العائلية | واجهة مجلس نجدي، شرفات نجدية، تقويم | شرفة صغيرة قبل العنوان |
| الدورات والبرامج | شاشة عرض، ميكروفون، أوراق وقلم، شهادة | وسم مؤطر |
| الرحلات | بوصلة، جبال وطريق، موقع | عنوان عريض ووسم ملون |
| المسابقات | كأس، منصة تتويج، وسام، قصاصات | عنوان عريض ووسم ملون |
| الإعلانات والصندوق | هوية أواصر أساساً، مكبر صوت، جرس، رسم بياني | هوية أواصر |

كل العناصر رسوم متجهة داخل الكود (`components/design/art/` مرتبة حسب المناسبة): بلا صور أشخاص أو مخلوقات حية، وبلا طلبات شبكة، وحادة في أي مقاس تصدير.
المستخدم يستطيع إخفاءها من **التخصيص ← إظهار العناصر ← زخارف المناسبة**.
صفحة المراجعة الداخلية: `/lab/art` (كل العناصر) و`/lab?size=story` (كل القوالب).

## الصور المصغرة للقوالب

صفحات القوالب تعرض صور WebP خفيفة (٢٤٠ و٤٨٠ بكسل) بدل رسم التصميم الكامل في كل بطاقة. توجد في `public/assets/<المناسبة>/thumbs/`.

- كل صورة مرتبطة ببصمة القالب في `data/thumbs.json`. إذا عُدّل قالب من لوحة الإدارة أو أُضيف قالب جديد، يُرسم مباشرة في المتصفح عند ظهوره (ولا تظهر صورة قديمة).
- **بعد تعديل القوالب أو محرك التصميم** أعد توليد الصور (يحتاج Chrome على الجهاز):

```bash
npm run dev            # في نافذة
npm run thumbs         # في نافذة أخرى
```

وعند تعديل كود التصميم نفسه زِد `DESIGN_VERSION` في `lib/thumbs.ts` قبل التوليد.

## الأداء: معاينة خفيفة وتصدير عالي الجودة

- محرك التصميم يُحمَّل عند فتح القالب فقط، لا في صفحات التصفح.
- الصورة المرفوعة تُعالج في الخلفية (Web Worker): نسخة ٢٤٠٠ بكسل للتصدير ونسخة ٩٠٠ بكسل للمعاينة. التصدير يبدّل إلى النسخة الكاملة لحظة الالتقاط.
- المعاينة تتبع الكتابة بأولوية أقل (`useDeferredValue`)، والطبقات الثابتة (الزخارف، النمط، الشعار) معزولة فلا يُعاد رسمها مع كل حرف.
- خط Cairo المتغير: ملف واحد لكل الأوزان.
- الشعارات محسّنة (تبسيط التدرجات اللونية دون فرق مرئي).

## التشغيل على جهازك (للمطوّر)

```bash
npm install
npm run dev      # http://localhost:3000
npm run build    # تحقق من البناء قبل الرفع
```

أثناء التطوير تفتح لوحة الإدارة بدون كلمة مرور. لتجربتها: انسخ `.env.example` إلى `.env.local` واكتب كلمة المرور.

## هيكل المشروع

```
app/                 الصفحات
components/design/   محرك التصميم (الأنماط الستة، طبقة المناسبات، الملاءمة التلقائية، QR)
components/design/art/  عناصر المناسبات البصرية (رسوم متجهة) مرتبة حسب المناسبة
components/editor/   نموذج البيانات، التخصيص، التصدير
components/admin/    لوحة الإدارة
lib/                 التواريخ والقوالب والتصدير والتخزين ومعالجة الصور
lib/occasions.ts     شخصية كل مناسبة البصرية
data/library.json    كل القوالب والنصوص والهوية
data/thumbs.json     بصمات الصور المصغرة
scripts/thumbs.mjs   مولّد الصور المصغرة
public/assets/awaser/          الشعار والهوية (SVG محسّنة)
public/assets/<المناسبة>/thumbs/  الصور المصغرة لكل مناسبة
```

**لإضافة قاعدة بيانات وحسابات لاحقاً:** المسودات تمر عبر واجهة `DraftStore` في `lib/drafts.ts`، والمكتبة عبر `lib/library.tsx`. يكفي تنفيذ هذه الواجهات بقاعدة بيانات (مثل Supabase) دون تغيير بقية الموقع.
